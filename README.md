# Naufal Azmi Alghifari — Portfolio

Static developer portfolio served from `index.html`.

## Tests

Run the dependency-free page contract suite with:

```sh
python3 -m unittest discover -s tests -v
```

The suite validates internal navigation targets, unique element IDs, external
link protection, the CV request action, the published certificate assets,
accessible social links, and the accessible mobile-menu state.
